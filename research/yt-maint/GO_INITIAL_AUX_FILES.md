# Bounded Go bootstrap auxiliary files and six-file validation

`qbmaint.ReplayInitialAux` ports `scripts/replay_maintenance_aux.py` for the
all-inactive, missing-NPC initial branch. It accepts exactly the original three
before files, an independently modeled final YTDATA world and separate news/
scoreboard date/clock inputs. It never loads an after target, executable or host
clock at runtime. Original source literals and PRINT USING masks were inspected
locally and reused; no new capture or binary query was needed.

## Qualified behavior

- YTNAME is copied unchanged from before bytes.
- YTYNEWS copies the old YTNEWS bytes, preserving all original control bytes.
- YTRMSG is empty; message compression is excluded.
- YTNEWS emits the maintenance, missing Wanderer, Xannoron and captured-Genesis
  base report for the admitted initial branch.
- YTSCORE.ASC emits the inactive player/team tables and the fixed bootstrap NPC
  row: 1000000 Xannor score (10000 fighters), 100.00%, zero Mercenaries/0.00%.

The fixed row is the original PRINT USING result for that exact admitted score,
not an after-file template or a general formatting implementation. Source masks
and all text are independently generated by the existing Python reference from
the immutable original executable, then compared with complete native files.
Different scores, active rankings and NPC encounter news are outside the API.

News and scoreboard sample DATE$/TIME$ independently. Dates are explicit ISO
calendar strings in the observed 2026..2028 range. Native `24:00:00` is accepted
without carrying to a new date; other invalid clocks fail. Output uses exact
CRLF separators and original EOF 1a. The scoreboard path is bounded to the
original YTSCORE.ASC configuration, excluding aliases and arbitrary output paths.

Admission requires default layout, empty inactive before-player assets, modeled
inactive after ranks, initially missing planets, exactly the three named NPCs
and positive Xannor force totaling 10000 in both worlds. Input files/world are
readonly; outputs are independent storage. Unsupported inventory, clock, date,
player, planet, deployment or path returns no partial map. Provenance of caller
inputs remains the caller's responsibility.

## Reused six-file oracles

The exporter authenticates the existing tail/base/mobile/source/clock chain,
reads original before files, runs independent Python synthesis from those
inputs, and only then compares all six files with native targets. Portable
fixtures contain deduplicated before name/news payloads, explicit sampled clocks
and six native SHA256 values per run. No output target enters either replay API.

Go tests reconstruct the entire world with the existing Go birth/mobile/base/
tail, port and rank writers, then call the auxiliary API. Every byte of all six
files matches in all 29 ordinary plain-route runs. Tests preserve inherited
name/news bytes, exact CRLF/EOF, separate clock dates and input/output isolation;
exporter corruption controls bind source, before payloads, clock and full file
inventories. Original capture bytes/hashes and acquisition attribution remain
unchanged. The three late-clock Wanderer-combat profiles remain excluded from
this Go composition and authenticated in parent research.

This is bounded six-file validation through research APIs/test composition,
not a public orchestration CLI, general maintenance, a native save loader or
playable integration. Modern save format 35 is unchanged. Next audit is public
research-only recipe/orchestration and excluded late-clock combat prefixes.
