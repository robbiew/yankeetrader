This profile integrates the measured positive SINGLE stock conversion from
[the acquisition controls](STOCK_CONVERSION.md). It reconstructs the original
November 2–4 prefix, applies one declared fixture to the complete modeled
November 4 parent, and computes November 5 without reading captured handoffs or
after-targets. All twelve acquired rational stock values are separate cases.

## Input and handoff boundary

The synthesis API accepts three original immutable before files, four typed
source-clock structures and a declared case. Startup seeding, chronological
helper TIMER calls, all 1000 port calendars/minutes, the four planet clock pairs,
and separate NEWS/SCORE clocks remain explicit. Observed RNG bytes are discarded
while constructing those inputs and are used only afterward as independent

fifteen-edit transformation installs the forced gateway and exact binary stock;

returned before comparison opens its first target. Core reads are restricted to
original YTMAINT constants/literals. No emulator capture, native query, provider
installation or historical corpus rewrite is needed for this integration.
