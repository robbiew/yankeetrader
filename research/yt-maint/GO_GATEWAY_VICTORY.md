# Bounded Go victorious Mercenary gateway continuation

`ReplayGatewayVictoryMercenary` accepts a modeled pre-Mercenary world and explicit
calculated state/source helper clocks. It returns an owned phase world and
calculated receipts, or nil world/zero statistics on every error. It ends before
lottery, final metadata and reports; this is not complete five-day Go/CLI replay
or a production maintenance selector. Historical phase APIs remain unchanged.

## Reused evidence and selected scope

The audit found two existing guarded profiles: `guarded-pickup` and `mine-guarded`.
The independent Python replay computes the original three-day parent, applies
declared fixture edits and completes both children before native comparisons.
Only the actual modeled pre-Mercenary worlds/states and consumed source clocks
become Go phase inputs. Captured routes, casualty results and RNG endpoints never
select synthesis branches.

## Source order

The phase draws once per positive physical defense, then reads mutable Mercenary
sectors descending. Every activation consumes the eager movement draw, clears
origin force/owner with source859e `00002800`, and derives /48cf helper target
rejection and directed BFS route from explicit source clocks. Lower-sector arrivals
activate again later in that same scan; higher-sector arrivals have passed it.

The optional single linked mine reseeds helper 2 /4aa4 and consumes exactly two
shrinking draws against the incoming force. Spent mines subtract to canonical
`00000000`. The entering gateway owner is negative, so combat follows the eager
ordinary branch draw. Each admitted defender count stays at most 37: all rounds
therefore use unit damage and do not qualify the both-sides-over-200 batch 150
branch. Every casualty is computed until the defenders die; attacker extinction
is outside this selected profile.

Victory saves canonical zero defense/owner fields. Crucially, it continues to
the next route edge rather than falling through to pickup using the newly cleared
owner. The whole remaining route is entered and the surviving force is saved at
its actual endpoint. Additional descending activations are derived from those
mutated records. Stock/governor/ground/name and stale group-cache bytes are not
changed; there are no capture/taking receipts in this API.

## Bounds and qualification

Admission retains default geometry, inactive humans, zero taxes, one initial
Mercenary deployment, integer directed graph and bounded whole physical NPC
inventories. The first phase has 97337 Mercenaries at 2368, a linked 37-fighter
Xannor guard, zero/one mine and canonical stock 37. The next phase has the measured
calculated origin/force pairs, a cleared gateway and canonical stock 40. Helper
clocks are ordered first-minute family 1 /48cf or family 2 /4aa4 inputs; computed
call sites enforce chronology. Other pickups, hazards, defenders, occupied-origin
branches, unmatched clocks or outcomes fail atomically.

All 12 selected modeled phase worlds and complete receipts match Go: 21 activations,
six victorious battles, three mine actions and six next-day continuations. Tests
compare complete worlds, ordered gates/reseeds/candidates/routes/entered prefixes,
mine and battle states/draws/casualties, separate faction conservation, raw zero
encodings, source-owned writes and input/output ownership. Late route, mine,
pickup or helper errors after internal combat writes publish nothing. The older
fatal-only guard is still tested separately.

The selected two profiles retain 72 six-file comparisons /432 native files and 660
RNG witnesses. The exporter also independently reruns the whole existing six-case
gateway audit: 216 comparisons /1296 files and 1962 witnesses. That wider audit is
not a claim that this Go API implements the four other profiles. Native bytes,
hashes, manifests, frozen acquisition sources and modeled synthesis rules remain
unchanged. Corruption controls reject altered inputs/receipts/audits/sources,
poisoned native outputs or RNG witnesses, enforce complete five-day synthesis
before target reads, and accept equivalent gzip only by uncompressed bytes.
