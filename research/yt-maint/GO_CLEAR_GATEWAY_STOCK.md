# Bounded Go clear-gateway stock conversion

`ReplayClearGatewayStockMercenary(before, EvolvedTailInputs)` accepts an owned
modeled pre-phase world, calculated state and explicit chronological /48cf target
clocks. It returns an independent world and `ClearGatewayStockStats`, or nil world
and zero statistics on unsupported context, including late route/clock failures.

## Reused evidence and boundary

The twelve [stock conversion controls](STOCK_CONVERSION.md) and their
[before-only Python replay](STOCK_CONVERSION_REPLAY.md) already qualify the native
behavior. No acquisition, runtime recovery, observation rewrite or hash change is
needed. The exporter runs the complete four-day Python chain before opening native
after-targets. It captures only the final Mercenary phase, not an entire Go day.

The 36 modeled pre/post worlds cover three source observations per stock value.
Independent native qualification remains 216 six-file comparisons /1296 files,
zero normalized bytes and 1656 new-stage RNG witnesses. Prefix witnesses are
checked without relabeling them as new stock targets.

## Derived behavior and strict admission

Default geometry, inactive humans, no tax-funded hiring, day 308, neutral Gateway
Cache at slot 3/sector 3000, zero bank/governor and no gateway defenses/mines are
required. Exactly one incoming deployment is admitted: 97337 at unoccupied sector
2368. The twelve canonical raw stocks range from the SINGLE immediately below
one to 189529.5, with quarter/half/three-quarter, half-tie and adjacent controls.
This is an enumerated measured profile, not arbitrary positive-stock admission.

Physical-sector draws and the eager movement draw precede chronological target
reseeds. Same-origin targets retry; directed BFS uses source warp order. The first
entered sector must be the clear gateway. Pickup stops the route, clears the full
raw stock to `00008000`, and saves 97337 plus `qbmbf.IntSingle` whole stock. The
origin retains departure residue `00002800`. Conversion adds no RNG draw.

Receipt metadata distinguishes the incoming 97337 stamp from saved force. All
subunit values transfer zero and suppress taking text; positive transfers retain
the original actor stamp. Fractions are discarded. Governor, ground, planet title,
stale caches and unrelated bytes are preserved. The historical friendly-garrison,
neutral-owner, departure and victorious gateway entry points are unchanged.

## Verification

Go golden checks compare all 36 complete phase-world hashes, RNG states/draws,
physical scans, target retries/routes, entered prefixes, reseeds and pickup
receipts. They verify 24 positive-taking and 12 silent captures, conservation,
raw clears, owned writes and immutable inputs. Unsupported stocks, defense,
mines, owners, geometry, hiring, actors, graph and late clock/route failures refuse
atomically. Existing friendly-garrison admission rejects these new clear contexts.

Exporter controls reject incomplete inventories, altered worlds/receipts/sources,
corrupt native targets and poisoned RNG witnesses. Full four-day synthesis must
precede each target group; equivalent compressed transport is allowed while the
complete uncompressed bytes remain exact. CI runs the exporter and its controls.

The API ends before lottery, publication and final metadata. Negative/unmeasured
stocks, arbitrary worlds, complete four-day Go/CLI integration, playable policies,
DOS save interoperability, native Windows and live BBS acceptance remain separate.
