# Pure Go initializer source generator

The `internal/qbinit` package now implements the bounded source-generation slice
of the [compatibility contract](COMPATIBILITY_CONTRACT.md). It produces an owned
568,687-byte result and generation statistics in memory. It does not publish a
playable world, write files, import saves or select a production profile.
That source-only milestone retained save 34. The subsequent playable `qb36-v1`
integration uses this package through safe projection and introduces save 35.

## Inputs and exact output

`Generate(Options)` requires an explicit raw post-RANDOMIZE state in the 24-bit
range and a canonical `YYYY-MM-DD` date in 2026–2028. January 10 now uses the
[verified class-dependent zero residue](JANUARY10.md); ten added original controls
cover January 9/10/11 across all admitted years and an independent repeat. An empty scoreboard field
selects `YTSCORE.ASC`; explicit text must be printable ASCII and at most 41 bytes.
The scoreboard field is never used as a path to write a file. Counts remain the
original 3,000 sectors, 1,000 ports, 50 inactive players and 100 inactive planets.

The generator uses `internal/qbrng`, explicit float32 boundaries, the original
weighted 908-entry DATA pool and exact bounded record serialization. It retains
FIELD/FAC zero residues, inherited inactive planet records, sparse warp columns,
Earth's self-link and original last-writer port collisions. These bytes remain
an exact source candidate; the playable projection enforces the
separate modern invariants described in the contract.

Ten native golden cases match every complete-world hash and every configuration,
player, sector, port and planet block hash: **5,686,870 output bytes** in total.
HQ selection, graph and placement endpoints, final RNG state, total/per-phase
draw counts, placement rejection counts, repairs and shortcut counts are also
checked. Four clock points retain independent native phase-state evidence;
draw counts remain replay bookkeeping rather than direct counter observations.

## Portable goldens and provenance

`internal/qbinit/testdata/native_initializer.json` is a compact portable fixture
of hashes, inputs, endpoint/count expectations and original source references.
Go tests read only this fixture and compiled Go DATA; they do not open research
files, original EXEs, Python or DOSBox. Portable checks also passed from a separate
minimal module containing only `qbinit` and `qbrng`.

The exporter independently validates retained targets, raw seed probes, clock/
return/auxiliary contracts and native-byte identities before deriving golden
byte hashes from the observed DOS worlds. It checks retained replay reports,
phase states and the Go DATA string against the original weighted DATA.
It never uses Go-generated bytes to choose the expected golden hashes.

```sh
# Ordinary Go validation: no emulator, Python or archive dependency.
go test -race ./internal/qbinit ./internal/qbrng

# Evidence/provenance verification in the full repository.
python3 scripts/export_qb_initializer_fixture.py --check
python3 scripts/test_qb_initializer_fixture.py

# Explicit fixture regeneration; verification never rewrites it.
python3 scripts/export_qb_initializer_fixture.py \
  --output internal/qbinit/testdata/native_initializer.json
```

Fixture corruption tests reject changed whole-world hashes, source seed hashes,
counts and removed cases. Go regressions check original overwrite behavior,
raw zero/January residues, inactive FIELD inheritance, invalid inputs, result
ownership and deterministic concurrent calls.

## Bounded work and error behavior

The source generator allows at most **1,000,000 random draws** by default; callers
can lower the limit but cannot raise it. Exhaustion returns `ErrDrawLimit` and
an empty result. This is an explicit modern termination boundary, not an original
DOS limit or a guarantee every state produces an admissible candidate. Fixed
geometry bounds the nonrandom graph-search work. No hidden reseeding, retrying a
different universe, fallback graph or partial candidate publication occurs.

Tests exhaust budgets during graph generation, placement and port construction,
and verify that the exact required draw budget still succeeds. The source API
preserves original collisions; the playable projection rejects them rather than repairing source bytes.

## Validation and next slice

The package's twenty native cases, full race-enabled Go suite and vet are checked
with the existing repository validations. CI also verifies fixture provenance
and its corruption controls. The source package adds no external dependencies;
the playable integration supplies the CLI described in the sysop guide.

The [safe projection/admission follow-up](PROJECTION.md) now rejects collisions,
protected HQs and disconnected graphs, validates modern homes and returns only an
unpublished candidate. CLI selection, typed saved provenance and complete
Genesis/admin-reset integration now ship as `qb36-v1` in save 35. General MBF arithmetic, arbitrary initializer inputs, exact
initial maintenance and DOS save interoperability remain separate work.
