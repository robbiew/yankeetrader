Standalone Linux x86-64/ARM64 and Windows x86-64 packages are attached, with SHA-256 checksums.

Each archive includes the executable, SYSOP_CHEAT_SHEET.md, full save/restore guidance and build provenance. No Go compiler or original DOS distribution is required.

Extract the matching package, read SYSOP_CHEAT_SHEET.md, create a separate data directory, initialize once, configure your BBS Door32 transport and schedule daily maintenance. Back up existing saves and retain the matching binary before upgrading. Check RELEASE_INFO.json for the save schema.

This release is created as a draft so the maintainer can review the packages and add milestone-specific release notes before publishing. Native Windows inherited-socket and live BBS acceptance remain host-specific verification.
